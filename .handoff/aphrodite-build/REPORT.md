# Aphrodite 0.1.0: delivered relational design instrument

Date: 2026-09-14. Manna: `mn-da6e1b`.

The complete first implementation is available as `agent-do aphrodite`. It constructs original semantic websites, evaluates them with nine computable contextual families, revises shared relationships, records human comparisons, proposes learned weights, and gives a fresh session the same executable model. The software is usable now. Its seed aesthetic hypotheses have not been validated as dependable human taste.

## What changed

Six typed relationship contracts connect real content nodes. Explicit three-relation constellations introduce non-additive terms. Nine family evaluators now compute from actual rendered geometry, glyph shape, image crop/texture, figure-ground, hierarchy, sequence and cross-viewport correspondence. Each reports its limited descriptor method.

The generator uses finite grammar expansion, a bounded seeded beam and shared coordinates. The main spacing relation is an affine equation in log dimensions. Presence, tempo, balance, character and scale propagate through the composition. Revisions list stale dependencies and remeasure the successor. An independent CSS correction cannot enter through the revision interface.

Selection uses the frozen perspective and requires every promised viewport/state to be measured and functionally eligible. Structural diversity is a separate condition within a declared affinity tolerance. A failed run has no selected export. Every run retains its source engine, program, browser observations, screenshots, decompositions, errors and hashes.

Offline preference fitting preserves exact attribution, ties and neither responses, separates whole held-out groups, and proposes weights without adopting them. A fresh-session packet carries the brief, model, material bytes and engine. There are zero npm dependencies and zero external model calls. The tool is registered in agent-do with sixteen commands and canonical tests.

## Evidence and limits

The old WP-0 files and copied evidence bundle remain unchanged. Its positive half-headline spacing prediction remains failed. The new negative elasticity is a contextual hypothesis informed by Erik's conditional preference; its magnitude was not fitted or declared universal.

The seed JSON contains 93 numeric settings, all attributed as authored. The fitter changes eight free family-weight dimensions, not the full parameter collection. No new human verdicts were manufactured, and no model was adopted. The prospective human transfer study in AP-WP-04 remains unperformed. Building its comparison/learning workflow does not count as passing that study.

The supported output domain is semantic HTML/CSS, local passive images, available font stacks, native links/disclosures and responsive reflow. The implementation is not a general application backend or a universal beauty theorem. Exact relationships provide constructive closure within their domain; the broader affinity model remains a testable proposal.

The gallery, full source, frozen runs, packets, validation evidence and this report are copied to iCloud Transfer. The report, operating guide and HLD/LLD are also saved together in the Obsidian vault. Exact delivery paths and content hashes are recorded in `DELIVERY.json`.
